# Node.js modules

## Installation

Node.js modules are usually installed using npm.
To install modules via npm, use:

```
$ npm install <module-name>
```

to install modules locally, or

```
$ npm install <module-name> -g
```

to install modules globally.

For example, to install `express`, you need to type:

```
npm install express
```
